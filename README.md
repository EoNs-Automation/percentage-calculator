# Percentage Calculator

A simple tool for common percentage calculations.

## Features

- Calculate what X% of Y is
- Find what percent one number is of another
- Calculate percentage increase or decrease
- Clean dark-themed web interface
- Available as both a Python script and a web tool

## Live Demo

[Try the web version here](https://percentage-calculator-b9ba6d.netlify.app/)

## How to Use (Python)

1. Run the script
2. Choose a calculation type
3. Enter the required values
4. View the result

- Python version of the calculator
- Web version (HTML + JavaScript)
